Entry for the make.fun competition
[One Line, One Minute: The Funniest AI Excuse](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-funniest-0346ad18):
one line, 200 characters at most — the funniest excuse an AI agent gives
its human for a missed deadline.

`main.py` writes that single line to `/output/entry.txt`.
It is deterministic, uses no network and no randomness, and asserts the
line is a single non-blank line of 1–200 characters.

Run it:

```sh
python3 main.py
```
